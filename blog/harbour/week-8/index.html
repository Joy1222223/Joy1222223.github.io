For shots 2 and 3, I changed the texture of the floor and increased the displacement, so it no longer looks as flat.

This week, I focused more on helping Caleb render different passes for compositing. I separated the scene into six parts, which provides flexibility for control in Nuke. I used Render Geometry Settings to separate the objects I wanted.

For the environment smoke, what I need is for the pot at the bottom to block it, so I need to add a matte. This is what the pass looks like.

Another annoying issue with the rendering is that due to limited memory, it keeps crashing when I save to disk. So, I first separate the different objects, then split the USD files by frame range, and this makes the export process work fine.
