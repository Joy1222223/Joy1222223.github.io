Substance Designer → Unreal Engine

Unreal Material Setup

One master material drives all four materials — tiling is exposed as Repeat U / V, and every map plugs into the same graph. For real depth I tried two ways of pushing the geometry with the height map:

A

Nanite Tessellation

Real displacement: the Nanite mesh is tessellated on the GPU.

  1. Turn on Nanite Support on the mesh.
  2. In the material, tick Enable Tessellation under Nanite.
  3. Plug the height map into the Displacement pin and use Magnitude (with Center 0.5) to set how far it pushes.
B

World Position Offset

Moves the vertices themselves: simple, but the mesh has to be dense.

  1. Multiply the height map by VertexNormalWS and a Height Intensity parameter.
  2. Connect the result to World Position Offset.
  3. The mesh has to be subdivided first — without enough vertices the shape can't change.

HDRI Lighting in Unreal

01

Environment sphere

Create a sphere and an environment material — Reflection Vector into Rotate About Axis drives the HDRI texture into Emissive, set to Unlit and Two Sided.

02

Sky Light

Change the Sky Light's Source Type to SLS Specified Cubemap and pick the HDR texture you chose as the cubemap.

03

Exposure

Add a Post Process Volume and set the exposure.

04

Ambient Cubemap

In the same volume, assign the HDRI as the Ambient Cubemap.
